# Справочник: бесплатные LLM-провайдеры

> ⚠️ Цифры ниже — состояние на **16.09.2026** по сверке ответов нескольких моделей, а не по официальной документации.
> Лимиты режут без предупреждения (в декабре 2025 Google срезал Flash с 250 до 20 RPD). **Перед стартом — сверять руками**, см. `wiki/workflows/quota-audit.md`.

## Роли в системе

| Провайдер | Роль | Ориентиры лимитов | Оговорки |
| --- | --- | --- | --- |
| **Groq** | Основной агентный движок: классификация, фильтр HR-шума, JSON-карточка | ~30 RPM; крупные модели ~1 000 RPD, мелкие до 14 400 RPD | Короткий контекст |
| **Gemini Flash** (AI Studio) | «Мозг» и длинный контекст: разбор компании, саммари отзывов | оценки расходятся: от 20 до ~1 500 RPD в разных ответах | Из РФ часто недоступен; free tier может учиться на промптах → `[CORE-012]` |
| **Cerebras** | Ночной батч (прогнать 200 вакансий) | ~30 RPM, ~1M токенов/день | Маленький контекст — урезать HTML до текста |
| **OpenRouter `:free`** | Аварийный фолбэк | 20 RPM / 50 RPD | 1 000 RPD только после пополнения ≈$10 — уже не «бесплатно» |
| **NVIDIA NIM** | Четвёртый слот цепочки | ~40 RPM | Нужна верификация телефона |
| **Ollama локально** | Обязательный последний рубеж + всё, что касается ПД | безлимит | 8–14B с рабочим tool calling, не 1–3B |
| **Cloudflare Workers AI** | Эмбеддинги, дедупликация | 10k «нейронов»/день | Не совсем Chat Completions → трение в LangGraph |

## Не закладываться

| Что | Почему |
| --- | --- |
| GitHub Models | Свернули к июлю 2026 |
| Hugging Face Inference | ~$0.10 кредитов/мес — не основа |
| Mistral как «безлимит» | Скорее ~$10 кредитов + согласие на обучение; оценка «1 млрд токенов/мес» не подтверждена |
| Cohere | Триал, часто non-commercial |
| AgentRouter, NexaAPI и пр. роутеры | Сомнительные обещания («$125 на баланс», «77+ моделей», «GPT-5.6 Sol») — маркеры галлюцинаций/скама |

## Критерии пригодности провайдера

| Свойство | Зачем |
| --- | --- |
| OpenAI-совместимый `/v1/chat/completions` | Один адаптер на LangGraph / CrewAI / n8n |
| Tool / function calling | Без него LangGraph и CrewAI ломаются |
| JSON / structured output | Нужна карточка вакансии, а не простыня текста |
| RPM, а не только RPD | Один шаг агента = 2–8 запросов |
| Стабильный base URL | Фоновый воркер не должен ломаться каждую неделю |

## Старт одним днём

Groq + LiteLLM + Ollama — достаточно, чтобы агенты ходили с tools и не падали при исчерпании лимита.
