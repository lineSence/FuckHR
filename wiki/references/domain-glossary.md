# Справочник: глоссарий

| Термин | Значение |
| --- | --- |
| **PLMIA** | Personal Labour Market Intelligence Agent — класс системы: job-агрегатор + AI-матчинг + company intelligence + risk analysis + multi-LLM gateway |
| **Детектор HR-брехни** | Модуль сопоставления утверждений вакансии с внешними данными |
| **Досье** | Агрегированная карточка компании: отзывы, история вакансий, публичные контакты, источники |
| **Карточка вакансии** | Итоговый JSON: вакансия + скор + выводы детектора + досье |
| **Скор** | Итоговая оценка соответствия вакансии запросу соискателя |
| **Квота / RPM / RPD** | Лимиты провайдера: запросов в минуту / в сутки |
| **Фолбэк-цепочка** | Упорядоченный список моделей в конфиге LiteLLM для одного этапа |
| **REGISTER / PROMOTE** | Шаги SEK: запись наблюдения в inbox / перевод в правило |
| **Кандидат против вакансии** | Система работает для соискателя: в Telegram приходят **вакансии**, не кандидаты |
