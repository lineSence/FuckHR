# Справочник: источники данных

## Вакансии

| Источник | Способ доступа | Статус |
| --- | --- | --- |
| hh.ru | **HTML-страницы** (`hh_html.py`): Open API с апреля 2026 отдаёт 403 без токена приложения, ADR-015 | Основной для РФ |
| Habr Career | Публичные страницы | Второй контур |
| Западные ATS: Greenhouse, Lever, Ashby | Публичные job-API | Хорошо автоматизируется (покрытие рынком 30–50%) |
| Карьерные страницы российских компаний | Индивидуальные адаптеры | Самая слабо покрытая часть, пишется руками |
| Telegram-каналы с вакансиями | Telethon | Опционально, см. `JobMonitor` в prior-art |

### Проверено на живых площадках (22.09.2026)

Фактическое состояние адаптеров — `docs/sources.md`, разбор отзовиков — `docs/review-sites.md`.
Правила разбора чужой площадки — `wiki/rules/scraping.md`.

| Площадка | Что выяснилось |
| --- | --- |
| zarplata.ru | Тот же движок, что у hh, но ключи сниппета `req`/`resp`/`cond`; отказывается от `Accept: application/json` (406), нужна браузерная строка |
| rabota.ru | Регион задаётся поддоменом, параметра `city` нет; `www.` — это Москва, а не Россия. Поиск нормализует запрос по словарю профессий: «специалист 1С» превращается в «специалист ui» и отдаёт дизайнеров |
| trudvsem.ru (Труд всем) | `opendata` API без `text` отвечает за 7 с, с `text` не отвечает и за 100 с при нашем таймауте 20 с: текстовый поиск непригоден, нужен обход по регионам с фильтром на нашей стороне |
| antijob.net, orabote.top, neorabote.net, trud.com | 403 Cloudflare: сверяется отпечаток TLS, cookie и UA не помогают `[SCR-005]`, нужен прокси |
| otzyvy-sotrudnikov.ru | Домен не резолвится |
| Dream Job, «Правда сотрудников», jobtrue.ru, hrlike.ru | Читаются обычным `httpx`; разметка даёт должность, город, стаж и оценки по критериям |

## Данные о компании (для детектора HR-брехни)

| Источник | Что даёт |
| --- | --- |
| Dream Job (и карточка работодателя на hh) | Отзывы сотрудников, оценки по аспектам |
| История публикаций вакансии (своя БД) | Частота перепубликации → текучка `[HRD-002]` |
| Публичные реестры юрлиц | Возраст, статус, масштаб компании |
| Сайт компании | Корпоративные контакты, состав команды (только публичное) |

Запреты и потолок по данным о людях — `wiki/rules/legal.md`.

## Выдача

Telegram Bot API: дайджест вакансий с досье и скором. Покрытие рынком — 80–90%, рисков нет.
