# Архитектура: обзор

## Контекст

Однопользовательская система для соискателя. Фоновый прогон собирает вакансии, проверяет работодателя
и присылает дайджест в Telegram. Управление — локальный веб-интерфейс на `127.0.0.1`.

## Модули

Таблица описывает файлы, которые есть в репозитории. Ранние имена (`collectors`, `extractor`,
`llm_gateway`, `store`, `scheduler`) были проектными обозначениями и в код не попали.

| Модуль | Ответственность | Зависимости |
| --- | --- | --- |
| `hh_html.py`, `hh.py` | сбор вакансий из HTML hh.ru, дампы сбоев | httpx |
| `score.py` | детерминированный отбор и скоринг без модели | `profile.yaml` |
| `conditions.py` | условия работы из описания вакансии | `llm_tasks` |
| `detector.py`, `detector_llm.py` | проверка утверждений вакансии по истории | `db`, `llm` |
| `websearch.py` | внешний поиск (SearXNG / Tavily / Brave) с кэшем | httpx |
| `reviewpage.py` | чтение и очистка страниц отзывов, кэш страниц | httpx |
| `dossier.py` | досье: отзывы, маркеры, риск, сводка | `websearch`, `reviewpage`, `llm` |
| `contacts.py`, `outreach.py` | публичные рабочие контакты и черновики писем | `websearch`, dnspython |
| `bot.py` | карточки и тревоги в Telegram | aiogram |
| `llm.py` | шлюз к моделям: профили, маршруты, кэш, потолок вызовов | httpx |
| `db.py`, `maintenance.py` | SQLite: вакансии, история публикаций, кэши, досье; очистка | — |
| `webui.py`, `jobs.py`, `ui_*.py` | интерфейс и запуск задач подпроцессами | стандартная библиотека |
| `run.py` | один прогон целиком | всё выше |

Отдельного планировщика в коде нет: расписание держит Task Scheduler (ADR-014).

## Границы системы

- Вне скоупа: автоотклики, обход капчи, сбор личных контактов людей.
- Один пользователь, одна машина, без мультитенантности.
- Интерфейс без авторизации и CSRF-защиты — только локальный адрес.

## Решения (ADR)

Ранние решения сохранены как история выбора. Где практика разошлась с ними, указано, чем заменено.

- **ADR-001. LiteLLM как единый шлюз.** *Заменено ADR-005 и ADR-017:* шлюз свой (`llm.py`), знает два
  OpenAI-совместимых адреса; LiteLLM остался возможным внешним прокси, а не обязательной зависимостью.
- **ADR-002. Облако — основа, Ollama — фолбэк.** В силе, реализовано выбором маршрута по профилю этапа.
- **ADR-003. hh.ru Open API вместо скрейпинга.** *Заменено ADR-015:* публичный `GET /vacancies` с апреля 2026
  отдаёт 403 без токена приложения, сбор идёт из HTML со своими паузами и дампами сбоев.
- **ADR-004. Скоуп — интеллект, а не отклики.** В силе и остаётся главным ограничителем: целевая метрика —
  «5 вакансий с полным досье».
