# Архитектура: пайплайн

```
1. COLLECT      hh.ru Open API / ATS / карьерные страницы → store
2. PREFILTER    Python: зарплата, гео, ключевые слова, дедуп по хэшу (без LLM)
3. EXTRACT      HTML/текст → JSON-поля вакансии
4. HR-FILTER    отсев HR-шума, извлечение проверяемых утверждений
5. MATCH        семантическое соответствие запросу соискателя
6. ENRICH       досье компании: отзывы, история публикаций, публичные контакты
7. VERIFY       сопоставление утверждений с данными → выводы с источниками
8. SCORE        итоговая карточка вакансии
9. NOTIFY       дайджест в Telegram
```

## Принципы

- Шаги 1–2 не используют LLM вообще `[LLM-005]`.
- Каждый LLM-шаг — через LiteLLM со своей цепочкой фолбэков `[LLM-002]`.
- Шаги 4–5 дешёвые и отсеивают 80–90%; шаги 6–8 работают по оставшимся 10–20% `[LLM-004]`.
- Шаг 6 можно уводить в ночной батч (Cerebras).
- Данные о конкретных людях на шаге 6 — только локальной моделью `[CORE-012]`.
- Каждый шаг идемпотентен по вакансии: перезапуск не дублирует работу (кэш по хэшу промпта).

## Бюджет вызовов

Один полный проход по вакансии = 4–10 LLM-вызовов. Целевой суточный потолок — 100–300 вызовов «умных» моделей.
