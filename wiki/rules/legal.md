# Правила: юридика и данные

> Главный практический риск проекта — не техническая сложность, а право.
> Проект целенаправленно работает с контактами людей, поэтому эти правила
> важнее любых оптимизаций.

### [LEG-001] Законный потолок по данным о людях
Собираем: должность, публичный профиль, корпоративный email, общий телефон
компании, рабочие каналы, которые человек сам опубликовал как рабочие
(Telegram в профиле Habr Career, email в GitHub-профиле, личный сайт).
Не собираем: личные мобильные, личные соцсети, домашние адреса, контакты родственников.
Основание: 152-ФЗ, GDPR.
Статус: validated → core `[CORE-013]`

### [LEG-002] API вместо скрейпинга
Скрейпинг hh.ru и LinkedIn нарушает их ToS. Приоритет: hh.ru Open API; для западных — публичные API ATS (Greenhouse, Lever, Ashby).
LinkedIn не используется и как источник контактов.
Статус: validated → core `[CORE-014]`

### [LEG-003] Обход защит не входит в скоуп
Антикапча, подделка сессий и массовые автоотклики — вне скоупа. В 2026 растут системы детекции автооткликов — это ещё и вредит кандидату.
Статус: validated

### [LEG-004] Статус источника фиксируется рядом с данными
Любой факт в досье хранит источник и дату. Без источника факт не показывается пользователю как утверждение.
Для контакта источник обязателен: адрес без ссылки на публикацию не используется.
Статус: validated

### [LEG-005] Популярность репозитория ≠ легальность подхода
Пример: `freellmapi` (26k+ ★) помечен автором как «personal experimentation only»; `llm-keypool` и `freeflow-llm` реализуют запрещённую `[LLM-003]` ротацию ключей.
Статус: validated

### [LEG-006] Прямой контакт — это не спам
Письмо конкретному человеку по конкретной вакансии с персональным содержанием —
легитимная деловая переписка. Массовая рассылка одинакового текста по списку
сотрудников — спам и репутационный риск. Границу держат `[OUT-004]`,
`[OUT-005]`, `[OUT-009]`.
Статус: core → `[CORE-022]`

### [LEG-007] Просьба не писать исполняется немедленно
Любой отказ, автоответ «не беспокоить» или жалоба закрывают человека и компанию
без исключений, запись в `contacts` со статусом `blocked`.
Статус: core
