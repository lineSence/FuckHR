# L3 — Inbox (draft-знания)

> Это не архив уроков, а конвейер. Пишет сам агент, без участия человека.

## Правила

- Лимит: **20 записей**. Записи старше **14 дней** без подтверждения удаляются.
- Формат: ровно 3 строки на запись.
- Триггеры записи:
  1. неожиданное поведение системы;
  2. найденный workaround;
  3. недокументированное поведение API;
  4. явная поправка от пользователя.
- Кандидат на promote: тема встретилась повторно или есть 3+ записи по одной теме.
- После promote запись удаляется отсюда, а в ответе выводится строка:
  `📚 Promoted: [TAG] → wiki/rules/<file>.md`

## Формат

```
- [YYYY-MM-DD] Что ожидалось vs что произошло
  Где: файл / модуль / эндпоинт
  Гипотеза: почему так, что проверить
```
