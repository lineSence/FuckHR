# MVP на Windows: самый короткий путь

Цель — работающая система за вечер, а не весь стек из ADR-006…013. Архитектура остаётся
целевой; здесь описано, что из неё берётся сразу, а что ждёт.

## Главное решение: MVP без LLM

Самый быстрый MVP не содержит ни одного LLM-вызова. hh.ru API отдаёт структурированный JSON:
вилка, гео, график, навыки, работодатель — всё уже в полях. Скоринг по стеку и вилке — это
десяток строк Python (`[CORE-015]`). Локальная модель, шлюз, эмбеддинги и детектор брехни
подключаются потом, к уже работающему потоку данных.

Причина не в лени: пока нет таблицы вакансий и слепков по дням, детектор HR-брехни
математически не может работать — его главный сигнал опирается на историю публикаций
(ADR-010). Значит, сбор данных надо запустить максимально рано, даже если аналитики ещё нет.

## Шаг 0. Окружение (30–40 минут)

```powershell
winget install Python.Python.3.12
winget install Git.Git
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install httpx pydantic pyyaml rapidfuzz aiogram python-dotenv structlog
```

Обязательно сразу:

- `PYTHONUTF8=1` в переменных среды. Без него русские описания вакансий ломаются на cp1251
  при любом письме в файл или выводе в консоль. Это самая частая потеря времени на Windows.
- Все пути — через `pathlib.Path`, никаких строк с `/`.
- Проект класть не в путь с кириллицей и пробелами (`C:\dev\fuckhr`).

Ни Node, ни Ollama, ни Docker на этом этапе не нужны.

## Шаг 1. Тонкий срез (один вечер)

```
hh.ru /vacancies → SQLite → дедуп → предфильтр по profile.yaml → скоринг → карточка в Telegram
```

Файлы:

| Файл | Что делает | Объём |
|---|---|---|
| `profile.yaml` | Навыки, вилка, гео, стоп-слова. На MVP — **руками**, без разбора резюме | 30 строк |
| `db.py` | Схема и запись: `vacancies`, `vacancy_snapshots` | ~80 |
| `hh.py` | Клиент hh.ru: поиск + карточка вакансии → модель `Vacancy` | ~120 |
| `score.py` | Совпадение стека (rapidfuzz), вилка, гео, стоп-слова | ~70 |
| `bot.py` | aiogram: карточка + кнопки статуса | ~80 |
| `run.py` | Один прогон всего пайплайна | ~40 |

Ключевая деталь: `vacancy_snapshots` пишется с первого запуска — `(vacancy_key, seen_at,
published_at, employer_id, salary_from, salary_to, is_active)`. Именно из него потом вырастёт
флаг «публиковалась 5 раз за 8 месяцев». Ключ дедупа — `(company_norm, title_norm)`;
`simhash(description)` добавляется позже.

hh.ru Open API на чтение вакансий работает без OAuth — достаточно своего `User-Agent`.
Регистрация приложения нужна только для действий от имени пользователя, которые в скоуп не входят.
Стартовать можно сразу.

## Шаг 2. LLM-слой (второй вечер)

```powershell
winget install OpenJS.NodeJS.LTS   # для FreeLLMAPI
winget install Ollama.Ollama       # есть родной инсталлятор для Windows
ollama pull qwen3:8b
```

На Windows без WSL и без Docker: FreeLLMAPI — обычный Node-процесс на `:3001`,
Ollama — служба на `:11434`. WSL только вредит: он забирает ОЗУ и мешает прямому
доступу к GPU через драйвер Windows.

Переменные Ollama задаются через «Переменные среды» и требуют перезапуска службы,
а не только терминала: `OLLAMA_NUM_PARALLEL=1`, `OLLAMA_MAX_LOADED_MODELS=1`,
`OLLAMA_FLASH_ATTENTION=1`, `OLLAMA_KV_CACHE_TYPE=q8_0`, `OLLAMA_KEEP_ALIVE=10m`.

Задача этого шага — только извлечение полей из описания и `instructor` для structured output.
Детектор брехни пока только на YAML-клише и детерминированных проверках (ADR-009,
слои 1–2 без LLM).

## Шаг 3. Расписание (30 минут)

Запуск два раза в сутки через Task Scheduler (ADR-014):

```powershell
schtasks /create /tn "FuckHR daily" /tr "C:\dev\fuckhr\.venv\Scripts\pythonw.exe C:\dev\fuckhr\run.py" /sc daily /st 08:00
```

`pythonw.exe` — чтобы не мигало консольное окно. Галочка «Выполнять независимо от
регистрации пользователя» обязательна, иначе задача молча не запустится при
заблокированном экране.

## Что отложено и почему

| Что | Почему не в MVP |
|---|---|
| LangGraph + checkpoint | Нужен только для паузы на подтверждение. До contact discovery паузы нет — простой скрипт достаточен |
| `sqlite-vec` | Семантический поиск не нужен на сотнях вакансий. Плюс на Windows надо проверить `enable_load_extension` в сборке Python |
| Playwright, карьерные страницы | Самый дорогой по ОЗУ и самый хрупкий слой |
| telethon, dreamjob | Вторичные источники; hh.ru даёт 80–90% потока |
| contact discovery, Tavily | Главная ценность проекта, но требует готового досье (`[OUT-002]`) |
| Разбор резюме в YAML | Руками быстрее, чем писать парсер (ADR-013 остаётся целью) |

## Критерий готовности MVP

Утренний запуск сам присылает в Telegram 5–10 карточек с вакансиями, отсортированными по скору,
без повторов со вчера. Контактов, досье и писем в MVP нет.
