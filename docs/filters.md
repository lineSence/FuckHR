# Фильтры и сортировки

Что умеют списки вакансий и компаний. Правила живут в `filters.py`, рисование — в
`ui_filters.py`.

## Как устроено

1. **Всё уходит в SQL до `LIMIT`.** Раньше страница брала первые N по скору и
   сортировала уже их: «по зарплате» показывало самую денежную из верхушки, а не из
   базы. Это не косметика, а неверный ответ на заданный вопрос.
2. **Из браузера в SQL не попадает ни один символ.** Имя фильтра ищется в словаре,
   кусок SQL берётся оттуда же, значение уходит параметром `?`. Неизвестное имя,
   чужое значение выбора и чужая сортировка молча заменяются умолчанием `[CORE-017]`.
3. **Пустое значение — не фильтр.** Иначе забытое поле тихо прячет половину базы.
4. **Активные условия всегда видны чипами.** Короткий список без объяснения читается
   как «база пуста» — самая частая причина не верить своему инструменту.

## Быстрые виды

Один клик — один заранее сформулированный вопрос. Вид не новая механика: он просто
подставляет те же параметры как умолчания, явное значение в адресе сильнее.

| Вакансии | Что показывает |
|---|---|
| Стоит открыть | висят, скор от 50, я их ещё не отклонял |
| Свежие | опубликованы за три дня |
| С живым контактом | есть не угаданный канал |
| Проблемные | инъекция в тексте или необеспеченные обещания |
| Не доехали в Telegram | прошли порог, карточка не отправлялась |
| По деньгам | вилка указана, сверху крупные |

| Компании | Что показывает |
|---|---|
| Красные | оценка работодателя — красные флаги |
| Без данных | досье есть, судить не по чему |
| С накруткой отзывов | отзывы похожи на заказные |
| С прямым контактом | есть канал к живому человеку |

## Фильтры вакансий

Слово в названии или компании, компания целиком, город, скор, зарплата от, свежесть в
днях, состояние (висит / снята — по последнему слепку), вилка (указана / скрыта),
отправлено ли в Telegram, моя отметка (нравится / нет / без отметки), контакт (любой /
не угаданный / нет), рынок (ниже / в рынке / выше), текст описания (генерация /
шаблонный / обычный), оценка работодателя, подозрительное (инъекция / необеспеченные
обещания / чисто).

Сортировки: скор, вакансия, компания, опубликована, замечена, зарплата, отклонение от
рынка.

## Фильтры компаний

Название, оценка работодателя, отзывов не меньше, оценка отзывов от, похоже на накрутку,
прямой контакт, вакансий не меньше. Сортировки: обновлено, компания, оценка, отзывов,
оценка отзывов, вакансий.

## Чего здесь нет намеренно

- **Второй стрелки сортировки.** У скора, денег и даты осмысленно только убывание, у
  названий — только алфавит `[CORE-025]`.
- **Сохранённых фильтров владельца.** Быстрые виды уже покрывают повторяющиеся вопросы,
  а хранилище личных наборов — это ещё одна таблица и экран управления ею.
- **Фильтра по навыкам из описания.** Навыки лежат строкой JSON; честный фильтр по ним
  требует отдельной таблицы, и его стоит делать вместе с полнотекстовым поиском.
