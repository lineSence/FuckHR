# Как участвовать

## Код

- Ветки: `feat/*`, `fix/*`, `docs/*` от `main`.
- Коммиты: Conventional Commits.
- PR: что сделано, что проверено, какие файлы документации затронуты.

## Документация

1. Новый факт о проекте → сначала `memory/inbox.md` (если это наблюдение) или сразу `wiki/`, если факт подтверждён.
2. Новый файл в `wiki/` → обязательно добавить в `wiki/_routing.md` (keywords) и `wiki/_index.md` (описание одной строкой).
3. Правило получает уникальный ID-тег `[TAG-NNN]`. Перед добавлением — `grep`, чтобы не дублировать.
4. `AGENTS.md` правим только осознанно: это core-уровень, изменение = изменение конституции проекта.

## Чек-лист PR

- [ ] Поведение изменилось → документация обновлена
- [ ] Новый файл документации → routing + index обновлены
- [ ] Новое правило → уникальный тег, дублей нет
- [ ] Обработанные записи удалены из `memory/inbox.md`
