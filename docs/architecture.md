# Архитектура проекта (для людей)

Рабочая версия для агента — `wiki/architecture/`.

## Цель

Довести до соискателя небольшое число вакансий с проверенным досье на работодателя, а не массовый поток откликов.

## Компоненты

Сбор → предфильтр без LLM → извлечение полей → фильтр HR-шума → матчинг → досье компании → сверка утверждений → скор → Telegram.
Детали: `wiki/architecture/pipeline.md`.

## Внешние зависимости

hh.ru Open API, ATS-API (Greenhouse/Lever/Ashby), источники отзывов, Telegram Bot API, бесплатные LLM-провайдеры через LiteLLM, локальная Ollama.

## Нефункциональные требования

- **Устойчивость к квотам:** падение провайдера снижает качество, не останавливает систему.
- **Приватность:** данные о людях не уходят в обучающиеся free-тиры.
- **Стоимость:** цель — 0 ₽ на LLM; бюджет 100–300 «умных» вызовов/день.
- **Прозрачность:** любой вывод о работодателе сопровождается источниками.
