# Архитектура

Краткий обзор для человека. Нормативные решения и их обоснование — в `wiki/architecture/`:
ADR-005 по шлюзу в `model-routing.md`, ADR-006…009 по остальному стеку в `tech-stack.md`.

## Контур

Система живёт целиком в RU-сегменте, на одной домашней машине (8 ГБ VRAM, 16 ГБ ОЗУ, i7-4790),
без внешнего AI-CLI и без облачной инфраструктуры. Единственная точка выхода к LLM — локальный
шлюз FreeLLMAPI на `http://localhost:3001/v1`.

## Цепочка

```
источники (hh.ru API, Habr Career, карьерные страницы, Telegram)
  → дедуп (rapidfuzz + simhash)
  → извлечение полей (instructor, профиль auto:fast)
  → скоринг соответствия
  → детектор HR-брехни (YAML-словарь + Python-проверки, спорное — в LLM)
  → contact discovery (руководитель отдела → тимлид → CTO)
  → черновик письма (профиль local-only: данные о людях не уходят наружу)
  → карточка в Telegram и пауза
  → подтверждение человеком
  → отправка
```

Всё до паузы автоматизировано. Пауза обязательна: ни одно письмо не уходит без подтверждения (`[CORE-023]`).

## Слои

- **Оркестрация** — LangGraph, состояние в `langgraph-checkpoint-sqlite`. Пауза на подтверждение — встроенный
  механизм прерывания графа, а не собственная очередь.
- **LLM** — FreeLLMAPI как единственный шлюз. Профили `auto:fast`, `auto:smart`, `auto:long`, `local-only`,
  `embeddings`. На данных о людях `model: "auto"` запрещён (`[CORE-012]`).
- **Локальный инференс** — Ollama, `qwen3:8b` Q4_K_M как рабочая модель, `bge-m3` для эмбеддингов.
  Chromium и Ollama не работают одновременно — 16 ГБ ОЗУ этого не позволяют.
- **Хранилище** — один файл SQLite с расширением `sqlite-vec`: вакансии, контакты, история переписки,
  чекпойнты графа, лог вызовов LLM.
- **Доставка** — Telegram-бот на aiogram 3, карточка с inline-кнопками `[Отправить] [Другой контакт] [Пропустить]`.
- **Запуск** — systemd timers, ночные батчи.

## Границы

- Западные ATS (Greenhouse, Ashby, Lever) и LinkedIn не поддерживаются.
- Адаптеры hh.ru и Habr Career портированы из `Fighter90/career-ops-ui` (MIT) и поддерживаются нами;
  апстрим не подтягивается.
- Законный потолок по данным о людях сохраняется: только рабочие каналы, никаких личных мобильных,
  личных соцсетей и покупных баз (`[CORE-013]`, `wiki/rules/legal.md`).

## Критерий готовности

Пять вакансий с полным досье и живым рабочим контактом за прогон (`[CORE-018]`).
Первая сборка идёт по короткому пути: hh.ru API → дедуп → извлечение → скоринг → карточка без контактов.
Contact discovery и детектор брехни подключаются следом.
