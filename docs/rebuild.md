# Пересчёт базы

Что делает `rebuild.py`. Зачем он нужен — коротко: пайплайн считает всё один раз, в
момент сбора, поэтому вакансия месячной давности живёт с тогдашним скором, без
ai-метки, без проверки на инъекции и без вектора. После правки профиля или порогов
список перестаёт быть сравнимым сам с собой.

## Запуск

```
python rebuild.py                      # все шаги
python rebuild.py --steps score        # только скоринг
python rebuild.py --steps injections,vectors
```

В интерфейсе — кнопка «Пересчёт базы» на странице запуска. Прогресс идёт строками
`[сделано/всего]`, как у сбора.

## Шаги и порядок

Порядок фиксирован (`rebuild.ORDER`) и не алфавитный: рынок нужен скорингу, улики —
оценке компаний, а оценка компаний — скорингу, если её учёт включён.

| Шаг | Что делает | Сеть |
|---|---|---|
| `market` | пересчитывает медианы зарплат по накопленным наблюдениям | нет |
| `injections` | гоняет детектор (ADR-020) по всем описаниям | нет |
| `claims` | сверяет обещания вакансий с историей публикаций (ADR-009) | нет |
| `companies` | пересчитывает оценку работодателей по всем уликам | нет |
| `score` | скор, причины, метка рынка и ai-метка по текущему профилю | нет |
| `vectors` | досчитывает эмбеддинги по всей базе, а не по 500 свежим | локальный эмбеддер |

## Чего пересчёт не делает

- **Не ходит в сеть.** Описания, отзывы, контакты и досье добираются только сбором:
  это работа `run.py`, и смешивать их нельзя — пересчёт должен быть безопасным
  в любой момент, в том числе без RU-IP.
- **Не трогает историю.** `first_seen_at`, `last_seen_at`, `notified_at` и `feedback`
  остаются как были. Иначе детектор решит, что вакансия висит дольше, чем на самом
  деле, а сброшенная отметка пришлёт в Telegram старые карточки.
- **Не зовёт модель**, кроме шага `vectors`. Без эмбеддера шаг возвращает ноль и
  пишет строку в лог `[CORE-017]`.
- **Не удаляет ничего.** Удаление живёт на странице «Очистка».

## Когда запускать

- поменял `profile.yaml`, веса или пороги — `score`;
- обновился на версию с новым детерминированным правилом — весь круг;
- включил эмбеддинги на непустой базе — `vectors`;
- накопилось несколько прогонов и хочется свежих флагов по перепубликациям — `claims`.
