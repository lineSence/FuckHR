# Легитимность отзывов и проверка разбора страниц

Отдельный, самый ранний вопрос сбора: это вообще отзыв сотрудника о нашей
компании? Всё остальное считается уже на выживших текстах.

| Вопрос | Где |
| --- | --- |
| Это отзыв о работе в этой компании? | `reviewlegit.py` |
| Отзыв настоящий или заказной? | `fake_reviews.py` |
| Как написан текст? | `aitext.py` |

Порядок обязателен: обрывок меню даёт «нет проверяемых деталей» и «длина как у
соседей», то есть накрутку на ровном месте.

## Проверка страницы

Название компании ищется на странице целиком: заголовок, текст, все найденные
отзывы. Нормализация — `company_key.normalize` (без кавычек и правовой формы),
сравнение нечёткое (`rapidfuzz`, порог `COMPANY_MATCH`). Не совпало —
**страница отбрасывается целиком**: поиск регулярно приводит на подборки
«отзывы о работодателях города», где каждый отзыв про своего работодателя.

Названия короче `COMPANY_MIN_CHARS` не проверяются: на них сравнение даёт шум.

## Проверка отзыва

Считается перевес признаков «за» над признаками «против» (`reviewlegit_rules`).
Принимается текст со счётом не ниже `ACCEPT_AT` и без жёстких причин.

| «За» | Вес | | «Против» | Вес |
| --- | --- | --- | --- | --- |
| говорит о работе | 2.0 | | отзыв клиента о товаре | жёстко |
| личный опыт | 1.5 | | шаблонная строка площадки | жёстко |
| плюсы и минусы | 1.5 | | ответ работодателя | жёстко |
| есть оценка | 0.5 | | меню и хлебные крошки | жёстко |
| есть дата | 0.5 | | обращение к читателю | 1.5 |
| | | | телефон, цена, ссылка | 1.5 |
| | | | о работе ни слова | 2.0 |

Ошибка «выбросили лишнее» дороже пропуска: выброшенный отзыв не оставляет
следа в досье. Поэтому признаков «за» больше, а мягкие причины сами по себе
текст не убивают.

## Шаблоны площадок собираются сами

Словарь boilerplate не ведётся руками — он всегда отстаёт от редизайна. Вместо
него `site_lines`: какая строка на какой площадке у какой компании встретилась.
Строка, попавшаяся у `BOILERPLATE_COMPANIES` (3) разных компаний одной
площадки, и есть вёрстка сайта. Стоп-лист получается самообучающимся и
привязан к площадке, а не к тексту вообще.

## Здоровье сбора

`site_health` копит по площадкам: страниц прочитано, отзывов принято,
отброшено, без даты. Строка на странице «Компании»:

> Сбор отзывов — dreamjob.ru: 42 отзыва, отброшено 6 (13%); orabote.top: 0
> отзывов, отброшено 0 (0%).

Ноль по площадке, на которую мы исправно ходим, означает редизайн или бан.
Тревога в Telegram по этому поводу не шлётся — решение владельца: прогон
не ломается, а строки достаточно.

Обе таблицы чистятся вместе с целью «Досье и отзывы о компаниях» в `/cleanup`.

## Golden-фикстуры

Разбор проверяется на настоящей вёрстке: `tests/fixtures/dreamjob.html` и
`tests/fixtures/pravda-sotrudnikov.html` — обрезанные страницы этих площадок.
Разметка настоящая, тексты отзывов написаны нами, имена и ники вырезаны
(`[CORE-012]`). Тесты — `tests/test_review_fixtures.py`: сколько отзывов вышло,
дата, точность даты, оценка, плюсы и минусы. После редизайна площадки тест
покраснеет.

Что показал первый заход на живые страницы и что из-за этого исправлено:

| Что было | Почему | Что сделано |
| --- | --- | --- |
| Один отзыв резался на три куска | Блок искался по подстроке `review` в классе, и `review__text`, `review__header` считались отдельными отзывами | Три способа поиска границы от точного к грубому: id вида `review123`, класс-контейнер целым токеном, прежний широкий поиск |
| Ни одной даты | Дата лежала в заголовке, а заголовок уезжал в соседний кусок | То же исправление; даты теперь читаются на обеих площадках |
| Ни одной оценки | dreamjob пишет оценку отдельной строкой «5,0», без слова «рейтинг» | `LONE_RATING_RE`: число 0–5 строкой целиком |
| Пустые плюсы и минусы | Заголовок секции стоит отдельным блоком, а текст брался только с той же строки | Берётся первая непустая строка после заголовка; добавлены формулировки «Что нравится?», «Отрицательные стороны» |
| Ни одного отзыва с «правды сотрудников» | 837 ссылок «отзывы в других городах» съедали потолок в 60 кусков | Потолок считается по принятым отзывам; служебные классы под контейнер не подходят |
| Живые отзывы выбрасывались как «о работе ни слова» | В словаре не было «руководство», «директор», «компания», «з/п» | Словарь пополнен по живым текстам |

Итог на образцах: 15 из 15 отзывов на странице dreamjob с датой и оценкой,
6 из 6 на «правде сотрудников» с датой, плюсами и минусами; ложных
срабатываний проверки легитимности не осталось.

Сбор образцов был временным: переменная `REVIEW_PAGE_DUMP_DIR`, галочка на
главной и `PageFetcher._dump_page` удалены, дампы из репозитория убраны.
Для следующей площадки код дампа проще написать заново, чем держать его
включённым постоянно.
