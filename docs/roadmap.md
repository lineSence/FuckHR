## Шаг 4. Качество досье — в работе

Это текущий фронт: контур работает, но вердикту пока нельзя доверять без чтения цитат.

- [ ] Разрешение сущностей: «ООО Ромашка» из вакансии и бренд в отзывах — одна компания
      (`rapidfuzz` уже в зависимостях, сравнение пока по точному совпадению названия)
- [ ] Проверяемые сигналы вместо тональности: частота перепубликации, срок жизни вакансии,
      дрейф вилки — считаются по накопленным слепкам, без сети и без модели
- [ ] Схема вердикта: каждое утверждение сводки обязано ссылаться на цитату и URL,
      утверждения без источника отбрасываются
- [ ] Ревизия словаря `PATTERN_RULES` на порядок слов и синонимы (см. `tests/test_polarity_order.py`)

## Шаг 5. Отложено осознанно

| Что | Почему не сейчас |
|---|---|
| LangGraph + checkpoint | паузы на подтверждение внутри прогона нет; последовательный `run.py` достаточен |
| `sqlite-vec`, эмбеддинги | семантический поиск не нужен на тысячах вакансий |
| Playwright / headless-браузер | +2–4 ГБ ОЗУ; включать, когда в логах `reviewpage` накопится доля страниц с HTTP 200 и пустым текстом |
| Postgres + pgvector | миграция с SQLite ради векторов при одном пользователе не окупается |
| Langfuse, Ragas | измерительная инфраструктура; сначала должно появиться что измерять |
