# Тесты

Цель тестов — не покрытие, а возможность проверять логику без походов на hh.ru.
Прогон по двум запросам с паузой 2 с и деталями по каждой вакансии — десятки минут
и лишний шаг к капче. Тесты идут за секунды и не делают ни одного сетевого вызова.

## Как запустить

```powershell
.venv\Scripts\pip install -r requirements-dev.txt
.venv\Scripts\python -m pytest -q
```

Один файл: `.venv\Scripts\python -m pytest tests/test_db.py -v`. Тесты запускаются и кнопкой
«Тесты» в интерфейсе — это та же команда в подпроцессе.

| Файл | О чём |
| --- | --- |

| `tests/test_published_at.py` | разбор даты публикации: ISO, миллисекунды, «вчера», «3 дня назад», «12 сентября» |
| `tests/test_hh_html.py` | извлечение JSON состояния, резервный разбор разметки, дампы сбоев и вырезание cookie |
| `tests/test_score.py` | стоп-слова, вилка ниже порога, отсутствие вилки, удалёнка |
| `tests/test_detector.py` | проверяемые утверждения и вердикты по истории публикаций |
| `tests/test_dossier.py` | маркеры, риск, рейтинги, сохранение и чтение досье |
| `tests/test_polarity.py` | отрицания: «зарплату не задерживают» не считается красным флагом |
| `tests/test_polarity_order.py` | порядок слов: «зарплату задерживают» и «задерживают зарплату» — один флаг |
| `tests/test_reviewpage.py` | вырезание обвязки страницы, кэш, потолок страниц, досье по тексту, а не по заголовку |
| `tests/test_bench.py` | оценка моделей: ловушки, откат письма, выбор победителя по этапам |
| `tests/test_websearch.py` | провайдеры поиска, кэш, потолок запросов, разбор выдачи |
| `tests/test_contacts.py` | угадывание почты, проверка MX, запрет личных каналов |
| `tests/test_outreach.py` | черновики писем и отказ отправлять что-либо самостоятельно |
| `tests/test_llm.py` | маршруты, профили, повторы и окончательные отказы шлюза |

## Правила

- Сеть в тестах запрещена. `tests/conftest.py` выключает загрузчик страниц отзывов
  (`REVIEW_FETCH_ENABLED=0`) для всех тестов; вместо живого hh.ru — синтетическая страница или `FakeClient`.
- Время передаётся параметром (`now=`), а не берётся из системных часов.
- База — всегда во временной папке `tmp_path`.
- Если сломался сбор на живом hh.ru, сначала положи сохранённую страницу из
  `data/failures/` в тест, потом почини парсер. Так регресс не вернётся незамеченным.
- Упавший тест чинится в коде, а не в утверждении теста: падение `test_polarity_order.py`
  нашло реальную дыру в словаре маркеров, а не ошибку ожидания.
