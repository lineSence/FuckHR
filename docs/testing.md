# Тесты

Цель тестов — не покрытие, а возможность проверять логику без походов на hh.ru.
Прогон по двум запросам с паузой 2 с и деталями по каждой вакансии — десятки минут
и лишний шаг к капче. Тесты идут за секунды и не делают ни одного сетевого вызова.

## Как запустить

```powershell
.venv\Scripts\pip install -r requirements-dev.txt
.venv\Scripts\python -m pytest
```

Один файл: `python -m pytest tests/test_db.py -v`.

## Что проверяется

| Файл | О чём |
| --- | --- |
| `tests/test_db.py` | слепки, is_active для исчезающих вакансий, три способа счёта перепубликаций |
| `tests/test_published_at.py` | разбор даты публикации: ISO, миллисекунды, «вчера», «3 дня назад», «12 сентября» |
| `tests/test_hh_html.py` | извлечение JSON состояния, резервный разбор разметки, дампы сбоев и вырезание cookie |
| `tests/test_canary.py` | когда пишем владельцу и когда молчим (cooldown) |
| `tests/test_score.py` | стоп-слова, вилка ниже порога, отсутствие вилки, удалёнка |
| `tests/test_pipeline.py` | весь прогон `run.main()` на поддельном клиенте: сбор → база → история |

## Правила

- Сеть в тестах запрещена. Вместо живого hh.ru — синтетическая страница или `FakeClient`.
- Время передаётся параметром (`now=`), а не берётся из системных часов.
- База — всегда во временной папке `tmp_path`.
- Если сломался сбор на живом hh.ru, сначала положи сохранённую страницу из
  `data/failures/` в тест, потом почини парсер. Так регресс не вернётся незамеченным.
