# Тесты

Цель тестов — не покрытие, а возможность проверять логику без походов на hh.ru.
Прогон по двум запросам с паузой 2 с и деталями по каждой вакансии — десятки минут
и лишний шаг к капче. Тесты идут за секунды и не делают ни одного сетевого вызова.

## Как запустить

```powershell
.venv\Scripts\pip install -r requirements-dev.txt
.venv\Scripts\python -m pytest -q
```

Один файл: `.venv\Scripts\python -m pytest tests/test_db.py -v`. Тесты запускаются и кнопкой
«Тесты» в интерфейсе — это та же команда в подпроцессе.

## Правила

- Сеть в тестах запрещена. `tests/conftest.py` выключает загрузчик страниц отзывов
  (`REVIEW_FETCH_ENABLED=0`) для всех тестов; вместо живого hh.ru — синтетическая страница или `FakeClient`.
- Время передаётся параметром (`now=`), а не берётся из системных часов.
- База — всегда во временной папке `tmp_path`.
- Если сломался сбор на живом hh.ru, сначала положи сохранённую страницу из
  `data/failures/` в тест, потом почини парсер. Так регресс не вернётся незамеченным.
- Упавший тест чинится в коде, а не в утверждении теста: падение `test_polarity_order.py`
  нашло реальную дыру в словаре маркеров, а не ошибку ожидания.
