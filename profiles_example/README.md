# Пример каталога профилей

Скопируй этот каталог в `profiles/` и правь под себя. Имя файла — идентификатор
профиля: оно попадает в `vacancy_profiles.profile_id`, в карточку и в фильтры,
поэтому переименование файла заводит новый профиль, а не переносит старый.

Каждый файл — полный набор критериев (ADR-023): запросы, гео, вилка, стек,
стоп-слова, веса и свой `min_score`. Общего между профилями ничего нет, кроме
фактов о владельце: досье на компании, оценки работодателей и контакты и так
общие для всей базы.

Путь задаётся настройкой `PROFILE_PATH`: файл — один профиль (как раньше),
каталог — все `*.yaml` внутри.
